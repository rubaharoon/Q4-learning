## 📖 What is an LLM?

A **Large Language Model (LLM)** is an artificial intelligence system trained on massive amounts of text data. It understands and generates human-like language to perform tasks like:

- 💬 Text generation
- 🔍 Summarization
- ❓ Question answering
- 🧠 Translation
- 🤖 Code generation
- 📊 Data analysis

LLMs use deep learning architectures like **transformers** to model language patterns at scale.

## 🧠 Core Concepts

- **Transformer Architecture**  
  The backbone of all modern LLMs. Uses attention mechanisms to learn language structure.

- **Pretraining + Fine-tuning**  
  Models are pretrained on general data, then optionally fine-tuned for specific tasks (e.g., medical, legal, coding).

- **Tokenization**  
  Text is broken into tokens (words, subwords, characters) for processing.

- **Prompt Engineering**  
  How you phrase your input (prompt) significantly affects the output of an LLM.
